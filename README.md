# Meter Flash Editor

Редактор графики приборных панелей Toyota и Daihatsu (процессор Fujitsu MB91F05x + внешняя флешка MX29GL640 / MX29GL320): перевод надписей, просмотр и правка картинок, проверка дампа и пересчёт контрольных сумм.

Открыть: https://klouner.github.io/meter-flash-editor/

Работает целиком в браузере — файлы никуда не отправляются. Исключение — автоматический перевод: распознанный с картинок японский текст (только текст) отправляется в онлайн-переводчик.

## Какие файлы загружать

| | Файл | Размер |
|---|---|---|
| Обязательно | Дамп внешней флешки MX29GL640 или MX29GL320 (TSOP48) | 8 или 4 МБ |
| Ключ | Прошивка процессора MB91F058 (MF), расшифрованная — для 838001AL7002 (83800-1AL70), 838001AV2100 и 83801D165000 (83800-BAA50, экран стоит боком) уже встроена | ≈1 МБ |
| Не нужны | WF (64 КБ), EEPROM 93C86 (2 КБ), зашифрованные файлы iProg (proc.bin) | |

## Какие приборки уже поддерживаются

| Номер графики | Прошивка процессора | Флешка | Автомобиль (предположительно) | Надписей |
|---|---|---|---|---|
| 838001AL7002 | 838001AL6003 · 591.01.01.03 | MX29GL640, 8 МБ | Toyota Corolla Axio / Fielder Hybrid (NKE165), 2013–2017 (?) | 223 |
| 838001AV2100 | 838001AV2100 · 591.01.01.03 | MX29GL640, 8 МБ | Toyota Corolla Axio / Fielder Hybrid 2017+, графика как у 1AL70 (?) | 225 |
| 83801D165000 | 83800BAA5000 · D11DTFT | MX29GL320, 4 МБ | Daihatsu со Smart Assist и вертикальным экраном: Rocky / Toyota Raize или Tanto (?) | 144 |

Модель автомобиля определена по содержимому надписей, «?» — не подтверждено на реальной машине. Для любой другой модели нужна расшифрованная прошивка процессора (MF): редактор найдёт в ней таблицу картинок, а надписи распознает и переведёт автоматически.

## Порядок работы

1. «Открыть файлы…» — дамп (и MF для другой модели).
2. «Обзор и проверка» — ключ найден, предупреждений нет.
3. «Перевод надписей» — поправить русские варианты, «Применить все переводы».
   Для модели без встроенного словаря — «Распознать и перевести автоматически»: японский текст читается с картинок в браузере (Tesseract.js, при первом запуске докачивает ≈2 МБ), перевод — онлайн-переводчиком. Рядом с японским текстом показывается английский перевод для справки: по нему проще понять смысл, если русский машинный перевод вышел кривым. Результат можно править: клик по японскому тексту — исправить распознанное, поле ниже — русский вариант. Одинаковые надписи, уже переведённые в другом дампе, подхватываются автоматически.
4. «Сохранить BIN» — контрольные суммы пересчитываются автоматически.
5. Записать файл программатором в ту же микросхему с проверкой. Оригинальный дамп хранить отдельно.
