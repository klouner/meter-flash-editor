# Meter Flash Editor

Редактор графики приборных панелей Toyota (процессор MB91F058 + внешняя флешка MX29GL640): перевод надписей, просмотр и правка картинок, проверка дампа и пересчёт контрольных сумм.

Открыть: https://klouner.github.io/meter-flash-editor/

Работает целиком в браузере — файлы никуда не отправляются.

## Какие файлы загружать

| | Файл | Размер |
|---|---|---|
| Обязательно | Дамп внешней флешки MX29GL640 (TSOP48) | 8 МБ |
| Ключ | Прошивка процессора MB91F058 (MF), расшифрованная — для 838001AL7002 / 83800-1AL70 уже встроена | ≈1 МБ |
| Не нужны | WF (64 КБ), EEPROM 93C86 (2 КБ), зашифрованные файлы iProg (proc.bin) | |

## Порядок работы

1. «Открыть файлы…» — дамп (и MF для другой модели).
2. «Обзор и проверка» — ключ найден, предупреждений нет.
3. «Перевод надписей» — поправить русские варианты, «Применить все переводы».
4. «Сохранить BIN» — контрольные суммы пересчитываются автоматически.
5. Записать файл программатором в MX29GL640 с проверкой. Оригинальный дамп хранить отдельно.
